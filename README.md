## 📌 Overview

**PlantDoctor** is an AI-powered plant care assistant that combines **computer vision, generative AI, and conversational interaction** to help users understand and take care of their plants.

Users can upload a picture of a plant and ask questions about its health, symptoms, or care requirements. The application uses **Google Gemini AI** to analyze the provided image and generate useful information such as plant identification, visible symptoms, possible causes, and recommended care actions.

PlantDoctor also integrates **Twilio WhatsApp**, allowing users to receive their generated plant-care plan directly on WhatsApp.

The project is built with **Python and Streamlit** and deployed using **Render**.

# ✨ Features

## 🌿 1. AI Plant Image Analysis

Users can upload an image of their plant.

Gemini AI analyzes the image and provides information about:

- Plant identification
- Visible plant symptoms
- Possible diseases or problems
- Potential causes
- Plant health observations
- Recommended actions
- Preventive care suggestions

---

## 🤖 2. Gemini AI Integration

PlantDoctor uses the **Google Gemini API** as the main AI engine.

Gemini is responsible for understanding:

- Plant images
- Natural-language questions
- Plant symptoms
- User descriptions
- Plant-care requirements

The AI generates responses dynamically based on the user's input.
